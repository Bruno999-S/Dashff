Fonte dos dados: amostra embutida (SAMPLE_DATA). Para ligar o dashboard à sua planilha real do Google Sheets, publique a aba "Gastos" como CSV (Arquivo → Compartilhar → Publicar na Web → CSV) e cole o link na constante SHEET_CSV_URL no início do script. A partir daí, toda vez que você abrir este dashboard ele busca a versão mais recente da planilha automaticamente.
